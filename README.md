# 源重构（YuChongGou）

爽文短视频素材采集、预处理与智能去重工具。

> **法律合规声明**：本工具仅供学习与个人创作使用。素材的版权与合规性由使用者自行负责；
> 本工具不存储、不传播任何第三方版权内容。采集功能仅调用各平台公开/官方接口，
> 未开放平台以"暂不可用"占位呈现，不提供逆向破解能力。

## 功能总览

- **素材采集**：多关键词批量搜索，Pexels/Pixabay 官方 API 接入；下载队列支持断点续传、
  并发上限（默认 3）、单次下载数量上限；三级目录自动归档（大类/关键词/日期）。
- **视频预处理**：去水印 / 去字幕 / 裁剪 / 比例调整 / 去原声 五项处理；
  自动+手动双模式；纯滤镜秒级路径与帧级修复路径自动分派，预算 ≤2×时长。
- **智能去重**：构图/运镜/节奏三维度重复度分析（0~100%），联网比对候选 + 手动参考；
  镜像/裁切缩放/调色/变速/边框 五手法引擎，轻度/中度/重度三档预设+自定义参数。
- **自定义 AI 服务**：设置页内置常用服务商预设（OpenRouter / DeepSeek / 智谱 GLM /
  Kimi / 硅基流动 / 魔搭 / 百炼 / 火山方舟 / Groq / 本地 Ollama 等），点击即预填地址；
  也可自定义任意 OpenAI 兼容服务（官方 API / 中转站）——填接口地址 + API Key →
  一键拉取模型列表 → 选择模型 → 设为默认；
  采集页「AI 扩展」围绕主词智能扩展素材搜索关键词（更多 AI 能力持续接入）。
- **任务中心**：统一状态机（七态）、失败重试（指数退避）、崩溃恢复、失败列表一键重新处理。
- **中英文界面**：默认中文，可在设置页切换（i18n）。

## 系统要求

- Windows 10 及以上
- 无需 Python 环境（使用打包版时）

## 安装

### 方式一：安装包（推荐）

1. 从 [Releases](../../releases) 下载 `YuChongGou_Setup_x.y.z.exe`
2. 双击安装 → 开始菜单/桌面快捷方式
3. 首次启动选择**素材工作目录**即可开始使用

### 方式二：便携版

下载 `YuChongGou_portable.zip` 解压即用。

### 方式三：源码运行

```bash
git clone <repo-url>
cd yuanchonggou
pip install -e ".[dev]"
python -m ych.app        # 或 python scripts/entry_point.py
```

源码运行需要本机可找到 `ffmpeg`/`ffprobe`（PATH 或 winget 安装位），
或将二进制放入 `runtime/` 目录。AI 模型放入 `runtime/models/`
（缺失时相应 AI 功能提示不可用，其余功能不受影响）：

```
runtime/models/
├── watermark_yolov8n_640.onnx      # 水印检测
├── subtitle_det_ppocrv4_mobile.onnx # 字幕检测
├── lama_fp32_512.onnx              # LaMa 修复
└── clip_vitb32_image.onnx          # 构图嵌入
```

## 使用教程（三大工作台，各三步）

| 工作台 | 步骤 |
|--------|------|
| 采集 | ① 输入关键词（逗号分隔可批量）→ ② 搜索 → ③ 勾选结果点「下载选中」 |
| 预处理 | ① 左侧勾选素材 → ② 选择处理项（手动模式可在画布框选区域）→ ③ 开始处理 |
| 去重 | ① 选素材 → ② 分析重复度后选方案（轻/中/重度或自定义）→ ③ 开始去重 |

输出位置：
- 预处理产物：`<工作目录>/…/<原名>_cleaned.mp4`（原文件同目录）
- 去重产物：`<工作目录>/已去重/<镜像层级>/<原名>_deduped.mp4`

## 界面与快捷方式

- `Ctrl+1..5`：切换 采集 / 预处理 / 去重 / 失败列表 / 设置 五个页面
- 双击搜索结果卡片：浏览器打开素材来源页
- 底部状态栏：实时显示进行中任务数量、平均进度与批次完成度
- **深色主题**：默认跟随系统深浅色，可在「设置 → 通用 → 界面主题」
  切换 浅色 / 深色 / 跟随系统（即时生效，无需重启）
- 窗口大小 / 位置自动记忆；多条提示以堆叠 Toast 呈现，互不遮挡
- 搜索结果卡片显示平台缩略图（联网加载并缓存，加载失败不影响使用）

## 平台可用性说明

| 分类 | 平台 | 首版状态 |
|------|------|----------|
| 国内平台 | 抖音 / 快手 / B站 / 小红书 | 暂不可用（框架占位，社区适配中） |
| 国外平台 | TikTok / YouTube | 暂不可用（默认关闭） |
| 免费素材站 | Pexels / Pixabay | ✅ 可用（需在设置页填入官方 API Key） |

> Pexels/Pixabay 免费申请 Key：pexels.com/api 与 pixabay.com/api。
> Key 存储在系统凭据管理器（Windows Credential Manager），不上传、不入库。
>
> 「设置 → 服务」统一管理素材站与 AI 服务：列表页展示各服务状态；
> Pexels/Pixabay 点「编辑」填官方 Key 即启用；AI 服务点「添加 AI 服务」
> 进配置页——内置常用服务商预设（OpenRouter / DeepSeek / 智谱 GLM / Kimi /
> 硅基流动 / 魔搭 / 百炼 / 火山方舟 / Groq / 本地 Ollama 等），点击预填地址，
> 也可自定义任意 OpenAI 兼容服务（中转站）：接口地址 + API Key → 拉取模型 →
> 选模型 → 保存后「设为默认」。配置好即可在采集页使用「AI 扩展」生成搜索词。
> 注意 Key 一一对应：Pexels Key 只解锁 Pexels，Pixabay Key 只解锁 Pixabay。

## 常见问题（FAQ）

**Q: 提示"当前网络环境无法访问外网素材站"？**
A: Pexels/Pixabay 属国外站点，请配置代理后到「设置 → 网络 → 检测外网」重试。

**Q: 下载中断了怎么办？**
A: 支持断点续传——重新提交同一素材会从已完成的字节继续；程序崩溃重启后也会自动恢复。

**Q: 处理后的文件在哪里？**
A: 见上文"输出位置"。原文件保留且带只读保护，不会被修改或覆盖。

**Q: 去水印效果不理想？**
A: 自动检测依赖模型质量；可改用手动框选模式精确指定区域，处理前有预览确认。

**Q: 启动超过 5 秒？**
A: 机械硬盘首次启动可能偏慢（放宽至 8s）；后续启动有系统缓存会明显加快。

## 开发者

- 技术栈：Python 3.10~3.12 / PySide6 / ONNX Runtime / OpenCV / SQLite / FFmpeg
- 本地开发：`pip install -e ".[dev]" && pytest tests -q`
- 代码检查：`ruff check src tests` + `mypy`
- 覆盖率门禁：服务层 `>=80%`、核心层 `>=65%`、关键算法 `>=90%`（由 CI 运行）
- 打包：见 `scripts/build_exe.spec` 与 `.github/workflows/release.yml`
- 打 release tag：`git tag v0.1.1 && git push origin v0.1.1` 自动触发 GitHub Release

### 项目结构

```
src/ych/
├── app.py                # 入口：冷启动 ≤5s，信号与页面接线
├── context.py            # 懒加载 DI 组装
├── common/               # 全局类型、schema、文件工具
├── core/
│   ├── m1_capture/       # 采集：插件、下载、搜索协调
│   ├── m2_preprocess/    # 预处理：去水印/字幕/比例
│   ├── m3_dedup/         # 去重：构图/运镜/节奏 + 手法引擎
│   ├── m4_scheduler/     # 调度：状态机、重试、崩溃恢复
│   └── m5_library/       # 素材库：归档、索引、工作目录
├── services/
│   ├── s1_media/         # ffmpeg、probe、帧提取
│   ├── s2_ai/            # 远程/本地 AI 服务
│   ├── s3_db/            # SQLite + DAO
│   ├── s4_net/           # HTTP、限流
│   └── s5_base/          # 配置、i18n、日志
└── ui/                   # PySide6 页面：采集/预处理/去重/失败/设置
```
