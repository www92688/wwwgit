## 一、已修复并验证 ✓

### 1. 登录窗口"一闪而过"（pythonw 无标准流）
- 根因：`启动应用.bat` 用 pythonw 启动应用，`spawn_cookie_login` 用 `sys.executable`
  拉起 cookie_fetcher → 子进程也是 pythonw，stdin/stdout/stderr 全为 None，
  浏览器弹出后脚本在首个 `print()` 即崩溃。
- 修复：`_douyin_backend.spawn_cookie_login` 自动换控制台版 python.exe。
- 验证：子进程存活 6s+（pythonw 下 1 秒内死）。

### 2. 登录浏览器 ERR_PROXY_CONNECTION_FAILED
- 根因：机器残留死代理（Clash 127.0.0.1:7897）+ Chromium 代理解析（WPAD），
  `proxy=per-context`、`direct://` 都会被劫持；实测仅 `--no-proxy-server` 能直连
  （douyin.com 返回 200）。
- 修复：cookie_fetcher 启动浏览器加 `args=["--no-proxy-server"]`（VENDORED.md 补丁 1）。

### 3. "已登录抖音"误判（未登录却显示已登录）
- 根因：`has_real_cookies` 只查 msToken（匿名会话也有）；登录线程成功判定把
  has_real_cookies 排在退出码之前（子进程闪退也判成功）。
- 修复：has_real_cookies 叠加 `sessionid/sid_tt` 登录态 Cookie 校验（匿名集没有）；
  退出码优先；`refresh_nickname` 启动时按文件态回滚残留的 `douyin_cookies_set=True`
  与昵称（自愈）；已清理残留匿名 Cookie（config_plugin.yml / config/cookies.json /
  .cookies.json）。

### 4. 登录确认无需按回车（自动检测）
- 根因：旧流程要用户回控制台按回车才落盘 Cookie，用户卡在"登录窗口打开中…"。
- 修复：cookie_fetcher 轮询 context.cookies()，出现 sessionid/sid_tt 即自动保存；
  回车监听改 daemon 线程作兜底（不能 asyncio.to_thread——executor join 会拖住
  进程退出）；浏览器提前关闭返回 "closed" 优雅退出（exit 1）。
- 验证：三条路径（自动检测/回车兜底/提前关闭）假 context 全过；UI Toast 文案
  已改为"自动保存，无需按回车"（i18n 已同步）。

### 5. 设置页代理单框（"填了正确的为啥不让我用"）
- 根因：host/port 两框，整段粘贴无处放、端口留 0 → `_apply_proxy` 静默停用。
- 修复：单框 `proxy_edit`；`split_proxy_address`（http_client.py）宽容解析
  `IP:端口`/`http://IP:端口`/纯 IP，失焦归一化写回（config 键不变）+ 即时状态反馈；
  HttpClient `_apply_proxy` 兜底解析（可自愈历史脏数据，含 IPv6 方括号）。

### 6. API Key 明文切换 + 模型手动导入 + 搜索耗时计数
- ai_key_edit / stock_key_edit 尾部加眼睛（QAction 切换 EchoMode）。
- 无公开下载源模型（watermark_yolov8n / clip_vitb32）按钮改「导入…」：
  `ModelDownloader.import_file` 复制→契约校验→原子落位，坏文件删除并报错。
- 搜索按钮每秒显示耗时"搜索中 {s}s…"（QTimer），抖音分钟级采集不再像卡死。

### 7. 抖音搜索超时（"搜索好久好久"）
- 根因：抖音封锁纯 HTTP 作品列表（ArgusSecurity 403），CLI 唯一路径是浏览器回补；
  默认 max_scrolls=240 / idle_rounds=8 滚起来没完，叠加偶发风控吃满 300s 超时。
- 修复：模板调优 `max_scrolls: 60` / `idle_rounds: 4`。
- 验证：**实测搜索 15s / 17 条作品（100%），生产配置路径复测 13s**。
