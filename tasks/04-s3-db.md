## 任务清单

### 连接与并发（`database.py`）
- [x] 库文件位置 `<用户数据目录>/YuChongGou/app.db`（%APPDATA%，不混入素材工作目录）
- [x] PRAGMA：journal_mode=WAL / foreign_keys=ON / busy_timeout=5000
- [x] thread-local 连接（threading.local + check_same_thread=False），每线程一个
- [x] `write(fn)` 统一串行锁包裹 BEGIN IMMEDIATE..COMMIT，避免 SQLITE_BUSY
- [x] `open()` 延迟连接：首次 DAO 访问才建立（启动提速）

### 迁移（`migrations.py`）

- [x] `MIGRATIONS: list[tuple[int, str]] = [(1, DDL_V1)]`；schema 版本用 `PRAGMA user_version`，不建版本表

- [x] DDL v1 九张表 + 索引逐一落地：
