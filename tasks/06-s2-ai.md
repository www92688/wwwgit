# S2 - AI 推理服务

> 模块目标：模型懒加载与会话缓存、四类推理能力统一出口（水印检测/字幕检测/修复/嵌入）、前后处理。M2/M3 只依赖 InferenceProvider 协议。首版 CPU。
> 设计依据：`design/max_design.md` 第九章
> 前置依赖：01-common；模型落位结论来自 SP-2/SP-3
> 输出位置：`src/ych/services/s2_ai/`

## 任务清单

### 基础设施
- [x] `provider.py`：`Detection(bbox, confidence, label, ts)` + `InferenceProvider` Protocol 四方法签名
- [x] `model_registry.py`：session(name) 懒加载+缓存；intra_op_num_threads=物理核-2（下限2）；providers=["CPUExecutionProvider"]
- [x] 模型文件落位 `runtime/models/` 四个 onnx（或按 SP-3 结论改为首启按需下载：URL/校验/断点续传走 S4）
- [x] 加载失败映射 AI001/AI002，功能不崩溃（UI 引导手动框选）

### 后处理纯函数（`postprocess.py` — 重点单测对象）
- [x] 定义并导出 `RegionSpan(bbox, t_start, t_end)` dataclass（temporal_cluster/stabilize 的返回类型，M2 帧级修复复用）
- [x] `nms(dets, iou_thr)`
- [x] `merge_boxes(dets, iou_thr)` 重叠合并(IoU>0.3)
- [x] `expand_bbox(b, margin)` 外扩并 clamp
- [x] `temporal_cluster(per_frame_dets, frame_ts, iou_link=0.5, presence_ratio=0.6)`：跨帧 IoU>0.5 链接成簇，活跃出现率≥60% 才认定静态区域 → RegionSpan(bbox,t_start,t_end)
- [x] `stabilize_regions(spans, fps)`：间隔<2s 且 IoU>0.5 合并延展消除闪烁

### TemplateMatcher 兜底（`template_matcher.py`）
- [x] templates/*.png 多尺度(0.5~1.5) matchTemplate(TM_CCOEFF_NORMED) 阈值 0.8
- [x] 置信度<0.45 或模型缺失时启用

### LocalProvider 实现（`local_provider.py`）
- [x] detect_watermark：letterbox 640 → YOLO 推理 → conf≥0.45 → NMS(0.45) → 反算原坐标 → 结果不足且模板库可用时 TemplateMatcher 补充
- [x] detect_subtitle：长边≤960 且 H/W 取 32 倍数 → PP-OCRv4 det → 多边形转最小外接矩形 → 合并重叠 IoU>0.3
- [x] inpaint：mask 外扩 12%（高斯羽化 8px）→ 裁 patch resize 512 → LaMa → 回贴羽化 alpha 混合；patch<32px 走 cv2.INPAINT_TELEA 快速通道
- [x] embed_frames：224 预处理(CLIP mean/std) → 批推理 batch=16 → L2 归一化输出 (n,512)

### 性能预算验证点
