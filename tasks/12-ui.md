# U - 表示层（PySide6 界面）

> 模块目标：主窗口导航 + 六大页面 + 公共组件，全部业务经 FakeScheduler 可注入，UI 不触网不碰 ffmpeg。
> 设计依据：`design/max_design.md` 第十五章；需求 4.2 易用性
> 前置依赖：全部服务与 core 模块（可按页面渐进接入）
> 输出位置：`src/ych/ui/`、`src/ych/app.py`、`src/ych/context.py`

## 任务清单

### 应用骨架
- [x] `app.py` main()：LogService.setup → AppContext DI 组装 → 主窗口启动（支撑冷启动 ≤5s：延迟非关键 import）
- [x] `context.py` AppContext 服务定位器：持有 ConfigService/Database/HttpClient/S1~S2/M4 调度器等单例引用

### U6 公共组件（`u6_common/`）
- [x] theme.qss 统一主题（浅/深跟随系统）
- [x] Toast 右上浮出提示（DL010 上限提示、平台不可用等非阻断反馈）
- [x] EmptyState 空状态占位
- [x] PlayerWidget(QMediaPlayer 预览)
- [x] progress_bar 进度条组件
- [x] 错误提示规范落地：Toast 显示 AppError.message + 「查看日志」按钮打开 logs 目录

### U0 主窗口（`u0_main/`）
- [x] MainWindow 左侧导航 + 页面栈（采集/预处理/去重/失败列表/设置/使用说明）
- [x] 工作目录引导向导：首次启动无 workdir 时强制引导选择并 validate

### U5 设置（`u5_settings/`）
- [x] 表单分组：通用(语言下拉/工作目录)/网络(代理三件套/「检测外网」按钮)/密钥(Pexels/Pixabay password 输入→keyring)/高级(并发 SpinBox/重试次数/只读保护开关)

### U1 采集工作台（`u1_capture/`）
- [x] capture_page 布局：顶部关键词栏 / 左侧平台分区 / 筛选面板 / 结果列表 / 底部下载队列

- [x] 平台分区开关组：国内默认开启；**免费素材站（Pexels/Pixabay）随国外总开关一同启停**（需求 1.2）；国外开关接 ForeignNetChecker，BLOCKED/OFFLINE 弹窗提示且开关回弹
