> 状态：待确认

## 一、项目概述

### 1.1 项目背景

爽文类短视频（抖音、快手等平台）高度依赖同质化的"解压"素材，如切割、清洗、修复、压面条等。这些素材在网络上被大量重复使用，直接搬用极易触发平台重复违规处罚，手动去重耗时且效果不稳定。

### 1.2 项目目标

开发一款名为 **「源重构」** 的 Windows 桌面软件，实现从"找素材"到"洗素材"再到"过原创检测"的全流程自动化，让爽文视频创作者不再为素材重复违规发愁。

### 1.3 软件基本信息

| 项目 | 说明 |
|------|------|
| 软件名称 | 源重构 |
| 软件形态 | 带界面的 Windows 桌面应用程序 |
| 安装方式 | .exe 安装包，双击安装后即可使用 |
| 分发方式 | GitHub 开源；可能上架国内软件平台 |
| 商业模式 | 暂时免费 |
| 用户体系 | 无需登录/账号，单用户本地使用 |
| 界面语言 | 支持中文和英文，用户可切换 |
| 界面风格 | 美观易用，具体风格由设计阶段确定 |

### 1.4 目标用户

- 抖音、快手等平台的爽文/解压类短视频创作者
- 需要批量处理视频素材的剪辑人员
- 缺乏专业视频后期技术但需要快速产出内容的个人创作者

## 二、功能需求

### 模块一：素材搜索与采集

#### 1.1 关键词搜索

- 用户输入关键词（如"地毯清洗""水管疏通""压面条"等）
- 支持同时输入多个关键词进行批量搜索
- 记录用户历史搜索词，方便快速复用

#### 1.2 采集平台

国内外平台分离设计，默认只搜索国内平台：

| 分类 | 平台 | 默认状态 |
|------|------|----------|
| 国内平台 | 抖音、快手、B站、小红书 | 默认开启 |
| 国外平台 | TikTok、YouTube | 默认关闭，用户手动开启 |
| 免费素材站 | Pexels、Pixabay | 随国外平台一同开启 |

- 国内和国外在界面上分区展示，互不干扰
- 国外平台功能开启前，工具检测用户当前网络环境是否具备外网访问能力
  - 有外网能力：正常使用
  - 无外网能力：弹出提示，告知用户当前无法采集外网资源

> 注：各平台采集能力受其公开接口和反爬策略限制，具体支持情况以实际实现为准。

#### 1.3 素材筛选条件

用户可设置以下筛选条件，全部提供：

| 筛选项 | 说明 |
|--------|------|
| 时长范围 | 设定视频最短/最长时长（如 10 秒 ~ 3 分钟） |
| 画质要求 | 选择目标分辨率（如 720p / 1080p / 原始画质） |
| 文件大小 | 设定文件大小的上下限（如 5MB ~ 100MB） |
| 水印情况 | 三个选项：有水印、无水印、不限制（都采集） |

#### 1.4 下载数量控制

- 用户可设置单次搜索的**下载数量上限**（如最多下载 20 条）
- 达到上限后自动停止下载，并提示用户

#### 1.5 批量下载

- 支持搜索结果列表的预览（缩略图 + 时长 + 画质 + 文件大小信息）
- 支持全选、勾选部分、按条件筛选后一键批量下载
- 下载过程显示进度条和当前状态（下载中/已完成/失败）
- 支持断点续传，下载中断后可恢复

#### 1.6 自动分类存储

素材下载完成后按三级目录自动归档：

```
工作目录/
├── 清洗类/
│   ├── 地毯清洗/
│   │   ├── 2026-08-22/
│   │   │   ├── douyin_地毯清洗_001.mp4
│   │   │   └── douyin_地毯清洗_002.mp4
│   │   └── 2026-08-24/
│   │       └── kuaishou_地毯清洗_001.mp4
│   └── 水管疏通/
│       └── 2026-08-24/
└── 切割类/
    └── ...
```

- **第一级：大类** — 默认取自用户搜索的关键词归纳，用户可手动归并或重命名大类
- **第二级：关键词** — 对应本次搜索的具体关键词
- **第三级：日期** — 下载日期，格式 YYYY-MM-DD
- 文件命名规则：`平台名_关键词_序号.mp4`（如 `douyin_地毯清洗_001.mp4`）

### 模块二：视频预处理

#### 2.1 可视化操作面板

- 提供图形界面面板，用户可选择要处理的素材
- 支持勾选素材（全选、按文件夹全选、手动勾选）
- 处理模式：**单个处理** 和 **批量处理** 两种都要支持
- 点击"开始处理"后自动执行
- 处理完成后显示结果列表（成功/失败/跳过）

#### 2.2 预处理功能清单

| 功能 | 说明 |
|------|------|
| 去水印 | 去除视频画面上的水印标识 |
| 去字幕 | 去除视频画面上的文字字幕 |
| 裁剪 | 裁切视频画面区域 |
| 比例调整 | 调整视频画面比例（如 16:9、9:16、1:1 等） |
| 去原声 | 去掉视频的原始音频轨道 |

#### 2.3 去水印功能

支持两种操作模式：

- **自动检测模式**：工具自动识别水印位置和区域，进行定位和擦除
  - 支持平台 Logo 水印（如抖音右下角标识、B 站播放器水印等固定位置水印）
  - 支持任意位置水印（画面中任意位置出现的文字或图案水印）
- **手动框选模式**：用户在视频画面上手动框选水印区域，工具对选区进行擦除修复

去水印后对擦除区域进行画面修复，不能出现明显的黑块或模糊斑块。用户可预览处理效果。

#### 2.4 去字幕功能

支持两种操作模式：

- **自动检测模式**：工具自动识别字幕区域，进行擦除修复
  - 支持硬字幕（烧录在画面上的文字）
  - 支持软字幕（独立字幕轨道，直接剥离）
  - 支持中英文字幕识别
- **手动框选模式**：用户手动框选字幕区域，工具对选区进行擦除修复

#### 2.5 处理结果

- 预处理后的素材输出为 MP4 格式
- 处理后的文件存放在原文件同目录下，文件名添加 `_cleaned` 后缀（如 `douyin_地毯清洗_001_cleaned.mp4`）
- 保留原文件不被覆盖

### 模块三：智能去重

#### 3.1 重复度检测

提供两种对比方式：

- **自动搜索对比**：工具根据本地素材的特征，自动在指定平台上搜索相似/同源视频进行比对
- **手动提供对比视频**：用户自行上传或指定对比视频文件，工具进行比对

两种方式可单独使用，也可结合使用。

**对比平台：**

| 平台 | 状态 |
|------|------|
| 抖音、快手、B站 | 必选，默认开启 |
| TikTok、YouTube | 可选，用户手动开启 |

**比对维度：**

- 画面构图：主体位置、景别、角度的相似度
- 运镜轨迹：镜头移动方式（平移、推拉、跟拍等）的相似度
- 剪辑节奏：画面切换频率、转场方式的相似度

输出重复度百分比（如"与 3 个网络视频相似度超过 80%"），用户可查看具体比对结果详情。

#### 3.2 去重处理手段

工具提供以下 5 种去重处理手段：

| 手法 | 说明 |
|------|------|
| 镜像翻转 | 水平/垂直翻转画面 |
| 画面裁切/缩放 | 调整画面显示区域，裁掉边缘或缩放画面比例 |
| 调色/滤镜 | 修改亮度、对比度、饱和度、色温等参数，或应用滤镜风格 |
| 变速处理 | 整体加速/减速，或局部变速 |
| 加边框 | 在画面四周添加装饰性边框 |

#### 3.3 去重策略

提供两种策略模式：

**预设方案（3 档）：**

| 方案 | 适用场景 | 处理力度 |
|------|----------|----------|
| 轻度去重 | 重复度较低（< 50%）的素材 | 组合 1~2 种手法，参数微调 |
| 中度去重 | 重复度中等（50%~80%）的素材 | 组合 2~3 种手法，参数适度调整 |
| 重度去重 | 重复度较高（> 80%）的素材 | 组合 3~5 种手法，参数大幅调整 |

工具根据检测结果自动推荐对应档位，用户也可手动选择档位。

**自定义方案：**

- 用户自行选择要使用的手法，并调整各手法的具体参数（如裁切比例、变速倍率、调色参数、边框样式等）
- 用户可保存自定义方案，方便后续直接套用

两种模式可切换：先用预设方案生成版本，再切换到自定义模式微调。

#### 3.4 处理模式

- **单个处理**：对单个素材执行去重
- **批量处理**：对整个文件夹或勾选的多个素材一键批量去重
  - 批量处理时显示队列进度和单条处理状态

#### 3.5 去重结果输出

- 输出格式：MP4
- 保存位置：工作目录下的 **"已去重"专属文件夹**，内部保持与原素材相同的层级结构

```
工作目录/
├── 清洗类/
│   └── 地毯清洗/
│       └── 2026-08-22/
│           └── douyin_地毯清洗_001.mp4        ← 原素材
└── 已去重/
    └── 清洗类/
        └── 地毯清洗/
            └── 2026-08-22/
                └── douyin_地毯清洗_001_deduped.mp4  ← 去重后
```

- 显示去重前后的重复度对比（如"去重前相似度 92% → 去重后相似度 15%"）

## 三、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 单条素材处理失败 | 自动重试（可配置重试次数），重试仍失败则跳过该条，继续处理下一条 |
| 下载中断 | 支持断点续传 |
| 网络连接异常 | 提示用户检查网络，支持手动重试 |
| 平台采集接口变动导致失败 | 记录到失败列表，提示用户该平台暂时不可用 |
| 批量处理中部分失败 | 不影响其余任务继续执行 |
| 软件崩溃 | 不丢失已完成的文件，重启后可查看失败列表并重新处理 |

**失败记录：**

- 所有处理失败的素材统一记录在失败列表中
- 列表包含：文件名、失败原因、失败时间
- 用户可从失败列表中一键重新处理

## 四、非功能需求

### 4.1 性能要求

- 单条视频预处理时间不超过原视频时长的 2 倍
- 单条视频智能去重时间不超过原视频时长的 3 倍
- 批量下载时支持至少 3 个任务并行
- 软件启动时间不超过 5 秒
- 界面操作响应时间不超过 1 秒

### 4.2 易用性要求

- 界面语言：支持中文和英文，用户可在设置中切换，默认中文
- 操作流程直观，主要功能不超过 3 步操作即可完成
- 提供处理进度的可视化展示（进度条、状态文字）
- 操作失败时给出明确的错误提示和解决建议
- 提供"使用说明"入口，内含各功能的使用指引

### 4.3 稳定性要求

- 所有原始文件不做破坏性修改，处理结果另存为新文件
- 处理过程中软件崩溃不丢失已完成的文件

### 4.4 兼容性要求

- 操作系统：Windows 10 及以上版本
- 输出视频格式：MP4（H.264 编码，AAC 音频）
- 支持导入的视频格式：MP4、AVI、MOV、MKV、FLV 等常见格式

### 4.5 可扩展性要求

- 采集平台的适配采用插件式架构，方便后续新增平台支持
- 去重手法采用模块化设计，方便后续新增处理手段
- 代码结构清晰，模块间低耦合，便于社区贡献

## 六、约束与风险

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| 平台反爬策略升级导致采集失败 | 部分平台无法下载 | 采用插件式架构，支持快速更新适配 |
| AI 去水印/去字幕效果不完美 | 处理后画面有残留 | 提供手动框选模式作为补充，用户可预览效果 |
| 联网比对依赖外部服务可用性 | 比对功能不可用 | 支持手动提供对比视频作为替代方案 |
| 各平台接口变动 | 采集功能失效 | 社区共同维护，及时更新适配 |
| 外网平台访问受限 | 国外平台功能不可用 | 启动时检测网络环境，无外网能力时提醒用户 |

## 七、术语表

| 术语 | 说明 |
|------|------|
| 爽文视频 | 以解压、反转、打脸等"爽感"内容为主的短视频，常配合画外音叙述 |
| 解压素材 | 给人带来视觉舒适感和满足感的视频片段，如切割、清洗、修复等 |
| 去重 | 通过技术手段修改视频特征，使其不被平台判定为重复内容 |
| 硬字幕 | 直接渲染在视频画面上的文字，与画面融为一体，无法简单分离 |
| 软字幕 | 作为独立轨道嵌入视频文件中的文字，可以单独提取或关闭 |
| 特征比对 | 通过提取视频的画面等特征信息，计算视频之间的相似度 |
| 预设方案 | 工具内置的 3 档去重策略（轻度/中度/重度），按重复度自动匹配 |
